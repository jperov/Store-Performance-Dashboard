Description

This dashboard was created to provide retial chain management and ownership with a (holistic) view of individual store, and overall company performance in key metrics overtime.



The (most useful) feature of the dasbhoard is the ability to compare how key metrics have trended MoM in comparison to last year, providing insight into  



Key Features:
* KPI totals of Sales, DPT, UPT, and Total Upsells.
* KPI percent changes displyaing the percent change to the selected month last year.
* YTD line plots of key metrics with options to compare against last year or against the average store.

Functionality
* The Month selector controls the KPI bar and the first 3 charts.
* The Store selector changes every chart in the dashboard to the selected stores performance.
* Stores YTD metric charts can be compared to performance last year using the "Year" dropdown.
* Stores YTD metric charts can be compared to the average store performance using the "Show Avg" dropdown.
